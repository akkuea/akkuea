# pilot-payout-split JS

JS library for interacting with [Soroban](https://soroban.stellar.org/) smart contract `pilot-payout-split` via Soroban RPC.

This library was automatically generated by the Stellar CLI:

```bash
stellar contract bindings typescript \
  --rpc-url https://soroban-testnet.stellar.org \
  --network-passphrase "Test SDF Network ; September 2015" \
  --contract-id CBGDO2GUWYSDU4SK3SNJJHYX6HRADUNXCU7TKJFFGLRWA4FSRZNLAJ4J \
  --output-dir apps/shared/src/contracts/pilot/generated/payout-split \
  --overwrite
```

## Regeneration

After a contract redeploy, regenerate all three pilot bindings with a single command from the repository root:

```bash
cd apps/shared && bun run generate:pilot-bindings
```

This runs `stellar contract bindings typescript` for each of the three pilot contracts against their testnet contract IDs recorded in `apps/shared/src/contracts.testnet.json`.

After regeneration, the post-processed wrapper files in `apps/shared/src/contracts/pilot/` and the generated `src/index.ts` files in each `generated/` subdirectory must both be consistent. Do not hand-edit generated files.

## Usage

```ts
import { PilotPayoutSplitClient } from "@akkuea/shared";

const client = new PilotPayoutSplitClient({
  contractId: "CBGDO2GUWYSDU4SK3SNJJHYX6HRADUNXCU7TKJFFGLRWA4FSRZNLAJ4J",
  rpcUrl: "https://soroban-testnet.stellar.org",
  networkPassphrase: "Test SDF Network ; September 2015",
});

const evidence = await client.get_evidence({ cycle_id: "2025-01" });
```
